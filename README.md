ATOMIC 0.1
==========
Stand-alone atom feed generator for feed-only blogging

August 9, 2026

config - sets variables to fill in templates, number of posts to generate in feed, etc.
Templates - framework template for generating the ATOM feed
posts.db - sqlite3 database of all entries

Required:

* sqlite3
* markdown - any flavor, your pick
* uuid - script checks for /proc, uuidgen and uuid
* sed/awk/bash

When the config is generated, the timestamp and UUID are autogenerated and should not be modified.  The timestamp meets spec and you shouldn't need to modify it. If you need something specific and you know what you're doing, ignore me.  The UUID is for the whole feed and if it changes, certain feedreaders will balk thinking it's a new feed. So, once generated, it shouldn't ever change.
